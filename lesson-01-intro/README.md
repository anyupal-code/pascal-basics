# Урок 1. Введение, структура программы

## Цель

Познакомиться с языком Pascal, понять структуру программы,
написать и запустить первую программу.

## Ключевые понятия

- **Компилируемый язык** — исходник превращается в исполняемый файл целиком, до запуска.
- **Строгая типизация** — тип переменной задаётся явно и не меняется.
- **Регистронезависимость** — `Begin`, `BEGIN`, `begin` — одно и то же.
- **Операторные скобки** — `begin ... end;` ограничивают блок операторов.
- **Точка с запятой** — разделитель операторов (не ставится перед `end` и `else`).
- **Комментарии** — `{ ... }`, `(* ... *)`, `// ...`.

## Особенности языка

- Создан Никлаусом Виртом в 1970 г. для обучения структурному программированию.
- Диалекты: Turbo Pascal, Free Pascal, Delphi (Object Pascal).
- Код читаемый, близок к английскому, много ключевых слов.
- В этом курсе примеры рассчитаны на **Pascal ABC / PascalABC.NET**.
  Компилятор `fpc` (Free Pascal) тоже подходит, но отдельные примеры
  могут потребовать правок.

## Полная структура программы

Общий скелет с **всеми** возможными разделами:

```pascal
program Name;              { 1. Заголовок (необязателен в Free Pascal) }

uses                       { 2. Подключаемые модули }
  SysUtils, Math;

label                      { 3. Метки (для goto — устаревшее) }
  Start, Finish;

const                      { 4. Константы }
  N = 10;
  Pi = 3.14159;

type                       { 5. Пользовательские типы }
  TPoint = record
    x, y: Integer;
  end;
  TArr = array[1..N] of Integer;

var                        { 6. Глобальные переменные }
  a: Integer;
  p: TPoint;

{ 7. Процедуры и функции }

procedure PrintLine(n: Integer);       { процедура — не возвращает значение }
var
  i: Integer;                          { локальная переменная }
begin
  for i := 1 to n do Write('-');
  WriteLn;
end;

function Sum(x, y: Integer): Integer;  { функция — возвращает значение }
begin
  Sum := x + y;                        { имя функции = результат }
end;

{ 8. Основная программа }

begin
  a := Sum(3, 5);
  PrintLine(20);
  WriteLn('a = ', a);
end.                                   { точка обязательна }
```

> **Важно для Pascal ABC:** модули `SysUtils` и `Math` в примерах
> курса **не подключаются** — нужные функции (`IntToStr`, `Sqrt` и т.п.)
> доступны без них. Если компилятор ругается «Модуль не найден» —
> удалите строку `uses`.

### Порядок разделов

```
program
  ↓
uses
  ↓
label
  ↓
const
  ↓
type
  ↓
var
  ↓
процедуры / функции
  ↓
begin ... end.
```

- Разделы `label`, `const`, `type`, `var` могут повторяться и идти
  в любом порядке между `uses` и подпрограммами, но **до** первого `begin`.
- Подпрограммы идут **после** `var` и **до** основного `begin`.
- Точка с запятой разделяет операторы, но **не ставится** перед `end` и `else`.

### Минимальная программа

```pascal
begin
  WriteLn('Hello');
end.
```

Даже без `program`, `uses`, `var` — компилируется.

## Подпрограммы: кратко

**Процедура** — выполняет действия, ничего не возвращает:

```pascal
procedure Hello(name: String);
begin
  WriteLn('Hi, ', name);
end;
```

**Функция** — возвращает значение через своё имя:

```pascal
function Square(x: Integer): Integer;
begin
  Square := x * x;
end;
```

Параметры:
- **по значению** (по умолчанию) — копия;
- **по ссылке** — `var x: Integer` — изменение влияет на оригинал.

Подробно — в Уроке 6.

## Вывод

- `WriteLn(...)` — вывод с переводом строки.
- `Write(...)` — вывод без перевода строки.
