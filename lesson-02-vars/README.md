# Урок 2. Переменные, типы данных, константы, арифметика, ввод/вывод

## Цель

Научиться объявлять переменные и константы, работать с базовыми типами,
выполнять арифметические и логические операции, обмениваться данными
с пользователем через консоль.

## Ключевые понятия

- **Переменная** — именованная область памяти, значение которой можно менять.
- **Константа** — именованное значение, которое нельзя изменить после объявления.
- **Тип данных** — определяет, какие значения может хранить переменная и какие операции к ней применимы.
- **Присваивание** — оператор `:=`, записывает значение в переменную.
- **Строгая типизация** — переменная хранит значения только своего типа.

---

## 1. Переменные

Объявляются в разделе `var`. Формат:

```pascal
var
  имя: тип;
  имя1, имя2: тип;   { несколько переменных одного типа }
```

Правила именования:
- начинается с буквы или `_`;
- содержит буквы, цифры, `_`;
- не совпадает с ключевыми словами (`begin`, `end`, `var`, `if`, `then` и т.д.);
- регистр не важен (`MyVar` и `myvar` — одно и то же имя).

```pascal
var
  a, b: Integer;
  c: Real;
  flag: Boolean;
  letter: Char;
  name: String;
```

---

## 2. Основные типы данных

| Тип       | Размер / диапазон       | Назначение         |
|-----------|-------------------------|--------------------|
| `Integer` | 4 байта, ±2·10⁹         | целые числа        |
| `Byte`    | 0..255                  | целые без знака    |
| `Word`    | 0..65535                | целые без знака    |
| `LongInt` | 4 байта                 | целые              |
| `Int64`   | 8 байт                  | большие целые      |
| `Real`    | 8 байт                  | вещественные       |
| `Single`  | 4 байта                 | вещественные       |
| `Boolean` | True / False            | логический         |
| `Char`    | 1 символ                | символьный         |
| `String`  | произвольная длина      | строковый          |

> Примечание: размеры `Integer` могут отличаться в разных диалектах.
> В Pascal ABC и Free Pascal `Integer` — 4 байта.

---

## 3. Константы

Объявляются в разделе `const` **до** `var`. Значение задаётся при объявлении.

```pascal
const
  Pi = 3.14159;
  N = 10;
  Greeting = 'Pascal';
  Debug = True;
```

Константа не может быть изменена:

```pascal
Pi := 3.14;   { ошибка компиляции }
```

Зачем нужны константы:
- читаемость (имя вместо «магического числа»);
- защита от случайного изменения;
- удобство правки в одном месте.

---

## 4. Присваивание

```pascal
x := 10;          { целое }
y := 3.14;        { вещественное }
s := 'hello';     { строка }
f := True;        { логическое }
c := 'A';         { символ }
```

- Тип значения должен совпадать с типом переменной.
- `Integer` и `Real` частично совместимы, но с осторожностью:
  ```pascal
  x: Integer;
  x := 3.7;         { ошибка в строгом режиме }
  ```

## 5. Арифметические операции

| Операция              | Знак    | Пример  | Результат |
|-----------------------|---------|---------|-----------|
| Сложение              | `+`     | `3 + 2` | 5         |
| Вычитание             | `-`     | `3 - 2` | 1         |
| Умножение             | `*`     | `3 * 2` | 6         |
| Деление вещественное  | `/`     | `7 / 2` | 3.5       |
| Целочисленное деление | `div`   | `7 div 2` | 3       |
| Остаток от деления    | `mod`   | `7 mod 2` | 1       |

Приоритет (от высшего к низшему):
1. `*`, `/`, `div`, `mod`
2. `+`, `-`

Скобки меняют порядок:

```pascal
2 + 3 * 4     = 14
(2 + 3) * 4   = 20
```

Стандартные функции (доступны без модулей):

| Функция   | Действие                             |
|-----------|--------------------------------------|
| `Abs(x)`  | модуль числа                         |
| `Sqr(x)`  | квадрат (`x * x`)                    |
| `Sqrt(x)` | квадратный корень                    |
| `Round(x)`| округление до целого                 |
| `Trunc(x)`| отбрасывание дробной части           |
| `Int(x)`  | целая часть (вещ. результат)         |
| `Frac(x)` | дробная часть                        |

```pascal
Abs(-5)     = 5
Sqr(4)      = 16
Sqrt(16)    = 4.0
Round(3.6)  = 4
Trunc(3.6)  = 3
```

## 6. Логические операции

| Операция           | Знак   | Пример                    |
|--------------------|--------|---------------------------|
| И                  | `and`  | `(a > 0) and (b < 10)`    |
| Или                | `or`   | `(a = 0) or (b = 0)`      |
| Не                 | `not`  | `not (a > 0)`             |
| Исключающее или    | `xor`  | `a xor b`                 |

Операции сравнения (возвращают `Boolean`):

| Операция        | Знак  |
|-----------------|-------|
| Равно           | `=`   |
| Не равно        | `<>`  |
| Меньше          | `<`   |
| Больше          | `>`   |
| Меньше или равно| `<=`  |
| Больше или равно| `>=`  |

```pascal
(a > 0) and (b > 0)     { оба положительны }
(a = 0) or (b = 0)      { хотя бы один ноль }
not (x < 0)             { x не отрицательно }
```

> `=` — это **сравнение**, а `:=` — **присваивание**. Не путать.

## 7. Ввод и вывод

### Вывод

```pascal
WriteLn('Hello');            { строка + перевод строки }
Write('x = ');               { без перевода строки }
WriteLn('x = ', x);          { несколько значений подряд }
WriteLn(a, ' ', b, ' ', c);  { с разделителями }
```

### Ввод

```pascal
ReadLn(x);                   { читает значение в переменную x }
ReadLn(a, b);                { читает два значения }
ReadLn;                      { просто ждёт Enter }
ReadLn(s);                   { читает строку }
```

- `ReadLn` читает до конца строки (Enter).
- Для чисел вводить можно через пробел или Enter.

### Форматирование вещественных

```pascal
WriteLn(x:0:2);              { всего знаков 0, после точки — 2 }
WriteLn(y:8:3);              { ширина поля 8, точность 3 }
```

Пример:

```pascal
x := 3.14159;
WriteLn(x:0:2);              { 3.14 }
WriteLn(x:8:3);              { "   3.142" }
```

## 8. Пример программы

```pascal
program SumAndAvg;

var
  a, b, s: Integer;
  avg: Real;

begin
  Write('Введите a: '); ReadLn(a);
  Write('Введите b: '); ReadLn(b);

  s := a + b;
  avg := s / 2;

  WriteLn('Сумма: ', s);
  WriteLn('Среднее: ', avg:0:2);
end.
```

Что демонстрирует:
- объявление переменных разных типов;
- ввод с клавиатуры;
- арифметику (`+`, `/`);
- неявное преобразование `Integer → Real`;
- форматированный вывод.
