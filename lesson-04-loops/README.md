# Урок 4. Циклы: `for`, `while`, `repeat`

## Цель

Научиться повторять действия нужное число раз или до выполнения условия.
Освоить три вида циклов и понять, когда какой применять.

## Ключевые понятия

- **Цикл** — конструкция, повторяющая блок операторов.
- **Итерация** — одно выполнение тела цикла.
- **Тело цикла** — операторы, которые повторяются.
- **Счётчик** — переменная, меняющаяся на каждой итерации.
- **Условие выхода** — выражение `Boolean`, определяющее конец цикла.

---

## 1. Цикл `for` (со счётчиком)

Используется, когда **заранее известно** число повторений.

```pascal
for i := 1 to 10 do
  WriteLn(i);
```

- `i` — счётчик, целого типа.
- Шаг всегда **+1** при `to`, **−1** при `downto`.
- Менять счётчик внутри тела **нельзя**.

### Обратный отсчёт

```pascal
for i := 10 downto 1 do
  WriteLn(i);
```

### Тело из нескольких операторов

```pascal
for i := 1 to 5 do
begin
  Write(i, ' ');
  s := s + i;
end;
```

### Счётчик — `Char`

```pascal
for c := 'a' to 'z' do
  Write(c);
```

### Счётчик после цикла

```pascal
for i := 1 to 10 do ;
WriteLn(i);   { i = 11 (или не определено — зависит от диалекта) }
```

> В Pascal ABC значение `i` после цикла **не определено** — не полагайтесь на него.

---

## 2. Цикл `while` (с предусловием)

Используется, когда число повторений **неизвестно** заранее.

```pascal
while условие do
begin
  ...
end;
```

- Условие проверяется **до** тела.
- Если условие сразу ложно — тело **не выполнится ни разу**.
- Нужно самим менять переменные, чтобы условие когда-то стало ложным.

### Пример: сумма цифр числа

```pascal
s := 0;
while n > 0 do
begin
  s := s + n mod 10;
  n := n div 10;
end;
```

### Пример: пока не введён 0

```pascal
ReadLn(x);
while x <> 0 do
begin
  sum := sum + x;
  ReadLn(x);
end;
```

---

## 3. Цикл `repeat` (с постусловием)

```pascal
repeat
  ...
until условие;
```

- Условие проверяется **после** тела.
- Тело выполнится **минимум один раз**.
- Выход — когда условие **истинно** (обратно `while`).
- `begin ... end` **не нужны** — `repeat` и `until` сами ограничивают блок.

### Пример: ввод до нуля

```pascal
repeat
  ReadLn(x);
  sum := sum + x;
until x = 0;
```

### Пример: проверка ввода

```pascal
repeat
  Write('Введите 1..10: ');
  ReadLn(x);
until (x >= 1) and (x <= 10);
```

---

## 4. Сравнение циклов

| Цикл     | Проверка  | Мин. итераций | Когда использовать             |
|----------|-----------|---------------|--------------------------------|
| `for`    | —         | 0             | известно число шагов           |
| `while`  | до тела   | 0             | условие может быть ложно сразу |
| `repeat` | после тела| 1             | тело должно выполниться хотя бы раз |

## 5. Прерывание и пропуск

### `break` — выйти из цикла

```pascal
for i := 1 to 100 do
begin
  ReadLn(x);
  if x = 0 then break;
  sum := sum + x;
end;
```

### `continue` — перейти к следующей итерации

```pascal
for i := 1 to 10 do
begin
  if i mod 2 = 0 then continue;
  WriteLn(i);   { только нечётные }
end;
```

> `break` и `continue` работают во всех трёх видах циклов.
> В **Pascal ABC** они также поддерживаются.

---

## 6. Вложенные циклы

```pascal
for i := 1 to 3 do
begin
  for j := 1 to 4 do
    Write(i * j:4);
  WriteLn;
end;
```

Вывод:

```
   1   2   3   4
   2   4   6   8
   3   6   9  12
```

- Внутренний цикл выполняется полностью на каждой итерации внешнего.
- Общее число итераций = произведение.

## 7. Типичные задачи

### Сумма 1..N

```pascal
s := 0;
for i := 1 to N do
  s := s + i;
```

### Факториал

```pascal
f := 1;
for i := 1 to N do
  f := f * i;
```

### Таблица умножения

```pascal
for i := 1 to 9 do
begin
  for j := 1 to 9 do
    Write(i * j:4);
  WriteLn;
end;
```

### Проверка на простое число

```pascal
isPrime := True;
i := 2;
while i * i <= n do
begin
  if n mod i = 0 then
  begin
    isPrime := False;
    break;
  end;
  i := i + 1;
end;
```

### Числа Фибоначчи

```pascal
a := 0; b := 1;
for i := 1 to N do
begin
  Write(a, ' ');
  c := a + b;
  a := b;
  b := c;
end;
```

## 8. Частые ошибки

- **Бесконечный цикл** — забыли изменить переменную условия.
  ```pascal
  i := 1;
  while i <= 10 do
    WriteLn(i);   { i не меняется → вечный цикл }
  ```
- **Точка с запятой перед `until`** — ошибка компиляции.
  ```pascal
  repeat
    ...
  until x = 0;   { без ; перед until }
  ```
- **Путаница `while` и `repeat`** — в `while` выход при **False**, в `repeat` — при **True**.
- **`for` с вещественным счётчиком** — недопустимо.
- **Изменение счётчика в `for`** — нельзя (в некоторых диалектах игнорируется).
