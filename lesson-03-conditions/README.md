# Урок 3. Ветвления: `if`, `case`

## Цель

Научиться управлять ходом программы с помощью условных операторов:
выполнять разные действия в зависимости от условий.

## Ключевые понятия

- **Условие** — выражение типа `Boolean` (True/False).
- **Ветвление** — выбор одного из нескольких путей выполнения.
- **Составной оператор** — блок `begin ... end;`, воспринимается как один оператор.
- **Вложенность** — один `if` внутри другого.

---

## 1. Оператор `if`

### Полная форма

```pascal
if условие then
  оператор1
else
  оператор2;
```

- Если условие истинно — выполняется `оператор1`.
- Если ложно — `оператор2`.
- **Перед `else` точка с запятой не ставится.**

### Краткая форма

```pascal
if условие then
  оператор;
```

Если условие ложно — ничего не выполняется.

### Пример

```pascal
var x: Integer;
begin
  ReadLn(x);
  if x > 0 then
    WriteLn('Положительное')
  else
    WriteLn('Не положительное');
end.
```

---

## 2. Составной оператор

Если нужно выполнить несколько действий — оборачиваем в `begin ... end`:

```pascal
if x > 0 then
begin
  WriteLn('Положительное');
  y := x * 2;
end
else
begin
  WriteLn('Не положительное');
  y := 0;
end;
```

- `begin ... end` — **один** оператор с точки зрения `if`.
- Точка с запятой **не ставится** между `end` и `else`.

---

## 3. Вложенные `if`

```pascal
if a > b then
  if a > c then WriteLn('a — максимум')
  else WriteLn('c — максимум')
else
  if b > c then WriteLn('b — максимум')
  else WriteLn('c — максимум');
```

**Правило:** `else` относится к **ближайшему** предшествующему `if`, у которого ещё нет `else`.

Чтобы избежать путаницы — используйте `begin ... end`:

```pascal
if a > b then
begin
  if a > c then WriteLn('a max')
  else WriteLn('c max');
end
else
begin
  if b > c then WriteLn('b max')
  else WriteLn('c max');
end;
```

---

## 4. Логические связки вместо вложенности

Вместо:

```pascal
if x > 0 then
  if x < 10 then
    WriteLn('0 < x < 10');
```

Пишем:

```pascal
if (x > 0) and (x < 10) then
  WriteLn('0 < x < 10');
```

Доступные связки: `and`, `or`, `not`, `xor`.

---

## 5. Оператор выбора `case`

Когда вариантов много и они проверяются по **значению** — удобнее `case`.

```pascal
case x of
  1: WriteLn('один');
  2: WriteLn('два');
  3, 4: WriteLn('три или четыре');
  5..10: WriteLn('от 5 до 10');
else
  WriteLn('другое');
end;
```

Особенности:
- Селектор (`x`) — **порядковый** тип: целый, `Char`, перечислимый, диапазон.
- Нельзя использовать `Real` и `String`.
- Ветки перечисляются через `;`.
- Ветка `else` — необязательна.
- `end;` обязателен (точка с запятой, т.к. `case` — это оператор).

### Группировка и диапазоны

```pascal
case c of
  'a', 'e', 'i', 'o', 'u': WriteLn('гласная');
  '0'..'9': WriteLn('цифра');
  'a'..'z', 'A'..'Z': WriteLn('буква');
else
  WriteLn('другой символ');
end;
```

### `case` с составным оператором

```pascal
case day of
  1: begin
       WriteLn('Понедельник');
       workday := True;
     end;
  6, 7: begin
          WriteLn('Выходной');
          workday := False;
        end;
else
  WriteLn('Неверный день');
end;
```

---

## 6. `if` vs `case`

| Критерий              | `if`                          | `case`                          |
|-----------------------|-------------------------------|---------------------------------|
| Условие               | любое логическое выражение    | совпадение с константой/диапазоном |
| Типы селектора        | —                             | только порядковые               |
| Диапазоны             | через `>=` и `<=`             | встроены (`5..10`)              |
| Читаемость при выборе | падает при >3 ветках          | сохраняется                     |
| Когда использовать    | сложные условия, диапазоны вещ.| выбор по значению целого/Char  |

---

## 7. Типичные задачи

### Знак числа

```pascal
if x > 0 then WriteLn('+')
else if x < 0 then WriteLn('-')
else WriteLn('0');
```

### Чётность

```pascal
if x mod 2 = 0 then WriteLn('Чётное')
else WriteLn('Нечётное');
```

### Максимум из трёх

```pascal
if (a >= b) and (a >= c) then max := a
else if (b >= a) and (b >= c) then max := b
else max := c;
```

### Калькулятор через `case`

```pascal
case op of
  '+': res := a + b;
  '-': res := a - b;
  '*': res := a * b;
  '/': if b <> 0 then res := a / b
       else WriteLn('Деление на ноль!');
else
  WriteLn('Неизвестная операция');
end;
```

---

## 8. Частые ошибки

- **`=` вместо `:=`** — `=` сравнение, `:=` присваивание.
  ```pascal
  if x = 5 then ...   { сравнение, ок }
  x := 5;             { присваивание }
  ```
- **Точка с запятой перед `else`** — ошибка компиляции.
  ```pascal
  if x > 0 then WriteLn('+');   { ← лишняя ; }
  else WriteLn('-');
  ```
- **Забыли `begin ... end`** — выполняется только первый оператор.
- **`case` по вещественному или строковому** — не компилируется.
