# Урок 5. Массивы

## Цель

Научиться хранить наборы однотипных данных и обрабатывать их в циклах:
ввод, вывод, поиск, суммирование, максимум/минимум.

## Ключевые понятия

- **Массив** — набор элементов одного типа, доступ по индексу.
- **Индекс** — порядковый номер элемента.
- **Размерность** — число измерений (1D, 2D, …).
- **Границы** — диапазон допустимых индексов, задаётся при объявлении.

---

## 1. Объявление массива

```pascal
var
  a: array[1..10] of Integer;       { 10 целых, индексы 1..10 }
  b: array[0..4] of Real;           { 5 вещественных, индексы 0..4 }
  c: array['a'..'z'] of Integer;    { индексы-символы }
```

- Индекс — **порядковый** тип: `Integer`, `Char`, перечисление.
- Границы задаются **константами** при объявлении.
- По умолчанию нижняя граница обычно 1, но можно 0 или отрицательное.

### Через константу размера

```pascal
const
  N = 10;
var
  a: array[1..N] of Integer;
```

Так удобнее: меняем `N` — массив переразмеряется.

### Свой тип

```pascal
type
  TArr = array[1..100] of Integer;
var
  a, b: TArr;
```

---

## 2. Доступ к элементам

```pascal
a[1] := 5;              { записать }
x := a[i];              { прочитать }
WriteLn(a[i + 1]);      { индекс — любое выражение целого типа }
```

- Индекс **вне границ** — ошибка времени выполнения (или мусор).
- В Pascal ABC при выходе за границы — исключение.

---

## 3. Ввод и вывод

```pascal
{ Ввод }
for i := 1 to N do
begin
  Write('a[', i, '] = ');
  ReadLn(a[i]);
end;

{ Вывод }
for i := 1 to N do
  Write(a[i], ' ');
WriteLn;
```

Ввод в одну строку через пробел:

```pascal
for i := 1 to N do
  Read(a[i]);
ReadLn;
```

## 4. Типовые задачи

### Сумма и среднее

```pascal
s := 0;
for i := 1 to N do
  s := s + a[i];
avg := s / N;
```

### Минимум и максимум

```pascal
min := a[1]; max := a[1];
for i := 2 to N do
begin
  if a[i] < min then min := a[i];
  if a[i] > max then max := a[i];
end;
```

### Поиск элемента

```pascal
found := False;
for i := 1 to N do
  if a[i] = key then
  begin
    found := True;
    pos := i;
    break;
  end;
```

### Подсчёт по условию

```pascal
count := 0;
for i := 1 to N do
  if a[i] > 0 then Inc(count);
```

### Реверс массива на месте

```pascal
for i := 1 to N div 2 do
begin
  t := a[i];
  a[i] := a[N - i + 1];
  a[N - i + 1] := t;
end;
```

## 5. Двумерные массивы

```pascal
var
  m: array[1..3, 1..4] of Integer;   { 3 строки, 4 столбца }
```

- Первый индекс — строка, второй — столбец.
- Доступ: `m[i, j]`.

### Ввод/вывод

```pascal
for i := 1 to 3 do
  for j := 1 to 4 do
    Read(m[i, j]);
ReadLn;

for i := 1 to 3 do
begin
  for j := 1 to 4 do
    Write(m[i, j]:4);
  WriteLn;
end;
```

### Сумма всех элементов

```pascal
s := 0;
for i := 1 to 3 do
  for j := 1 to 4 do
    s := s + m[i, j];
```

### Главная диагональ (квадратная матрица)

```pascal
s := 0;
for i := 1 to N do
  s := s + m[i, i];
```

## 6. Строки как массивы символов

Строка `String` — по сути массив символов с индексами от 1.

```pascal
var
  s: String;
  i: Integer;
begin
  s := 'Pascal';
  for i := 1 to Length(s) do
    Write(s[i], '.');
end.
```

- `Length(s)` — длина.
- `s[i]` — i-й символ (нумерация с 1).
- Изменять `s[i]` можно, но менять длину строки поэлементно нельзя.

---

## 7. Частые ошибки

- **Индекс вне границ** — `a[0]` при `array[1..N]`.
- **Забыли `ReadLn` после `Read`** — остаётся `\n` в буфере ввода.
- **`for i := 1 to N` вместо `N-1`** при обращении к `a[i+1]`.
- **Копирование массива целиком** — в Pascal нельзя `b := a`, только поэлементно (если это не `array of` или не в PascalABC.NET с динамическими массивами).
- **Путаница индексов** в 2D: `m[i, j]` — i строка, j столбец.
